# WEB78 – Data Analysis and Machine Learning with R and Python

## Overview

This repository contains practical assignments completed as part of the WEB78 course. The project explores data analysis, visualization, data preprocessing, and introductory machine learning using **R and Python**.

The objective is to apply analytical techniques to different datasets and develop practical skills in data exploration, statistical analysis, and predictive modeling.

## Projects and Assignments

### 1. Credit Data Analysis — R

**File:** `web78_aufgabe_1.R`

This assignment explores a loan-related dataset using R.

Key topics:
- Data cleaning and missing-value handling
- Exploratory data analysis (EDA)
- Descriptive statistics and correlation analysis
- Histograms and boxplots
- Analysis of relationships between loan status and selected variables

**Technologies:** R, data manipulation, statistical analysis, data visualization

### 2. COVID-19 Data Analysis — Python

**File:** `web78_aufgabe_2.ipynb`

This notebook explores COVID-19 data across countries and over time.

Key topics:
- Loading and preparing time-series data
- Filtering and aggregating country-level observations
- Exploring reported COVID-19 trends
- Creating visualizations to communicate patterns in the data

**Technologies:** Python, Jupyter Notebook, pandas, Matplotlib

### 3. Housing Data Analysis and Introductory Machine Learning — Python

**File:** `web78_aufgabe_3.ipynb`

This notebook investigates housing-related data and applies introductory analytical and machine learning techniques.

Key topics:
- Exploratory data analysis
- Outlier detection and correlation analysis
- Regression-based prediction
- Introductory classification with a stochastic gradient descent classifier

**Technologies:** Python, Jupyter Notebook, pandas, NumPy, Matplotlib, scikit-learn

## Installation and Requirements

### R assignment

Install R and, if desired, RStudio. Install the R packages required by `web78_aufgabe_1.R` before running the script.

### Python assignments

Python 3 and Jupyter Notebook are recommended. Install the required Python packages in your environment:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter openpyxl
```

Some packages may not be required by every notebook. Check the imports in each file and install any additional dependencies as needed.

## How to Run

1. Clone or download this repository.
2. Obtain the required datasets from an authorized source.
3. Place the datasets in the expected local directory and verify the file paths in each script or notebook.
4. Open the R script in RStudio and execute it.
5. Open the Python notebooks in Jupyter Notebook or JupyterLab and run the cells in order.

**Note:** The assignments may require adjustments to file paths, dependencies, or individual code cells depending on your local environment and dataset versions.

## Data and Responsible Use

Raw datasets are not automatically redistributed with this repository. Files whose licenses, redistribution permissions, or anonymization status have not been verified are excluded from Git version control.

Before using any dataset, verify its original source, applicable license, and permitted use. Do not upload personal, confidential, or otherwise restricted information to a public repository.
